Computer Room Reservation System
一个基于 C++ 实现的机房预约管理系统，采用父类 + 子类的面向对象设计，实现学生、教师、管理员三类角色的权限分离操作，
支持（一周内）机房预约、预约审核、人员管理、数据持久化（CSV 文件存储）等核心功能。

一、开发环境
开发语言：C++11 及以上
编译环境：Visual Studio / Dev-C++ / CLion / MinGW
依赖库：C++ 标准库（<iostream>/<vector>/<fstream>/<algorithm>/<string>）
运行环境：Windows（推荐）/ Linux / MacOS

三、核心设计思想
1.父类基架，子类分治：System作为主系统父类，封装公共数据和公共方法；Stu_System/Teacher_System/Admin_System公有继承主系统，实现各角色专属功能，保证权限分离、代码解耦。
2.面向对象特性：使用类的封装（属性私有化、方法公有化）、继承（子类复用父类代码）、运算符重载（==运算符实现登录验证），符合 C++ 面向对象开发规范。
3.轻量级数据持久化：通过 CSV 纯文本文件实现数据的启动自动加载和退出自动保存，无需数据库，简单易维护。
4.数据同步机制：子系统构造时从主系统拷贝最新数据，操作后同步回主系统，主系统统一保存至文件，保证数据一致性。


四、核心类说明
1. 人员类（Person.h/cpp）
包含三个平级类，封装各角色基础属性，重载==运算符用于登录验证：
(1)Student：m_Id(学号)、m_Name(姓名)、m_Password(密码)
(2)Teacher：m_Id(教师号)、m_Name(姓名)、m_Password(密码)
(3)Admin：m_Name(管理员名)、m_Password(密码)（按姓名验证登录）

2. 预约类（reservation.h）
封装单次预约的独立信息，作为机房类的组合成员，一条记录对应一次预约：
属性：roomname(机房名)、m_Name(预约人姓名)、m_Id(预约人 ID)、m_Date(预约日期)、m_Situation(预约状态)
预约状态：审核中/审核通过/审核未通过/取消预约

3. 机房类（room.h/cpp）
封装单台机房的所有信息，实现预约容量控制和预约记录管理：
基础属性：m_id(机房编号)、m_capicity(机房容量)
预约管理：m_size(一周 7 天已预约人数)、m_Res(该机房所有预约记录，vector<Reservation>)

4. 系统类（system.h/cpp）
(1)主系统父类 System
公共数据：m_Rooms(所有机房)、m_Stus(所有学生)、m_Teachers(所有教师)、m_Admins(所有管理员)
公共方法：文件读写 (info_from_file)、字符串分割 (split)、预约信息查看 (reservation_info)、数据统一保存 (save)
(2)三子系统子类（公有继承System）
[1]Stu_System：学生专属功能，仅操作机房和学生数据，无人员管理权限
[2]Teacher_System：教师专属功能，仅操作机房和预约数据，无人员管理权限
[3]Admin_System：管理员专属功能，操作所有数据，拥有系统最高权限


五、CSV 文件格式规范
所有 CSV 文件为逗号分隔、无表头、无空格格式，需与可执行文件在同一目录下，否则会导致数据加载失
1. student.csv（学号，姓名，密码）
	如：1，张三，123456
2. teacher.csv（教师号，姓名，密码）
	如：T001，李四，abcdef
3. admin.csv（管理员名，密码）
	如：admin，admin123
4. room.csv（机房编号，机房容量）
	如：1，30
5. log.csv（机房名，预约人姓名，预约人 ID，预约日期，预约状态	）
	如:机房1，张三，1，星期2，审核中


六、系统功能概览
1.学生角色
	登录验证（学号 + 姓名 + 密码）
	查看所有机房预约信息
	查看个人预约信息
	机房预约（判断容量，预约状态为「审核中」）
	取消个人有效预约（修改状态为「取消预约」）
2.教师角色
	登录验证（教师号 + 姓名 + 密码）
	查看所有机房预约信息
	预约审核（对「审核中」的预约标记「审核通过」/「审核未通过」）
3.管理员角色
	登录验证（管理员名 + 密码）
	查看所有学生 / 教师信息
	添加学生 / 教师（默认密码000000）
	删除指定学生 / 教师
	查看机房信息和所有预约日志
	清空所有机房的预约记录


七、使用注意事项
1.编译设置：确保编译器将 C++ 标准设置为C++11 及以上（如 VS 项目属性→C/C++→语言→C++ 标准）。
2.文件路径：所有 CSV 文件必须与编译后的可执行文件在同一目录下，否则会提示「文件打开失败」。
3.输入规范：
	(1)所有功能选择均输入数字（如 1/2/3），输入非数字会导致程序异常；
	(2)预约日期输入1-7（代表周一至周日），机房编号输入1-3，超出范围会禁止操作；
	(3)输入信息时不要带空格，否则会导致数据解析错误。
4.CSV 文件修改：如果手动修改 CSV 文件时，必须严格遵循逗号分隔、无表头、无空格规范，否则会导致数据加载失败。
5.正常退出：修改数据后需通过主菜单「0. 退出系统」正常退出，直接关闭程序会导致数据未保存。
